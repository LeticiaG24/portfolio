Project Overview & Goal

Sphera é um sistema de PDI (Plano de Desenvolvimento Individual) desenvolvido para apoiar empresas na gestão e acompanhamento do crescimento profissional de seus colaboradores. O projeto foi solicitado pela FATEC e desenvolvido como um projeto acadêmico com cliente real, tendo a empresa Youtan como parceira.
A aplicação tem como objetivo permitir o registro, acompanhamento e análise de PDIs, oferecendo relatórios e indicadores estratégicos para gestores e equipes de RH. Dessa forma, o sistema contribui para o alinhamento entre objetivos individuais e organizacionais, auxiliando na tomada de decisões e promovendo a valorização do desenvolvimento contínuo dos profissionais.

The Fullstack Architecture

Front-end

  • Desenvolvido com JavaFX para construção da interface gráfica
  • Estilização das telas utilizando CSS
  • Prototipagem das telas no Figma

Back-end

  • Desenvolvido em Java
  • Estruturação do projeto utilizando Maven
  • Geração de relatórios em PDF utilizando a biblioteca iText
  • Geração de relatórios em Excel utilizando a biblioteca Apache POI

Banco de dados

  • Criação do banco de dados utilizando MySQL

My Role & Core Contributions

  • Implementação da geração de relatórios de metas em PDF, utilizando a biblioteca iText
  • Criação de uma classe Controller para realizar a conexão entre a tabela de metas do JavaFX e o banco de dados MySQL
  • Participação ativa em sprints, reuniões diárias (dailies) e revisões, seguindo a metodologia Scrum

Challenges & Learnings

Um dos principais desafios do projeto foi o aprendizado e aplicação do padrão MVC, exigindo compreensão clara da separação de responsabilidades entre Model, View e Controller, especialmente no contexto do JavaFX.
Além disso, o trabalho com um cliente real trouxe desafios relacionados à comunicação, alinhamento de expectativas e adaptação a mudanças de requisitos ao longo das sprints.
O projeto Sphera consolidou minha evolução técnica e profissional, aproximando o ambiente acadêmico das demandas reais do mercado.
