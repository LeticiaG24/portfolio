Project Overview & Goal

O Sistema de Cadastro dos Encontros das Mães que Oram pelos Filhos é uma ferramenta desenvolvida para facilitar a organização, o registro e o acompanhamento das atividades do movimento. Com uma interface simples e intuitiva, o software permite cadastrar encontros, participantes, intenções de oração e grupos locais, garantindo mais agilidade e precisão na gestão das informações. Seu objetivo é apoiar a missão do movimento, oferecendo recursos que fortalecem a comunicação, a unidade e a continuidade das ações pastorais.

The Fullstack Architecture

Front-end

  • Desenvolvido com JavaFX para construção da interface gráfica
  • Estilização das telas utilizando CSS
  • Prototipagem das telas no Figma

Back-end

  • Desenvolvido em Java
  • Estruturação do projeto utilizando Maven
  • Geração de relatórios em PDF utilizando a biblioteca iText

Banco de dados

  • Criação do banco de dados utilizando MySQL
  • Modelagem do banco de dados conceitual e lógico com BrModelo

My Role & Core Contributions

Fui responsável por todo o desenvolvimento do back-end do sistema, atuando desde a criação da base do projeto até as funcionalidades finais. Minhas principais contribuições incluem:

  • Criação e configuração do projeto Maven
  • Modelagem e implementação do banco de dados MySQL
  • Desenvolvimento da lógica de negócio e filtragem de dados
  • Conexão das tabelas JavaFX com o banco de dados
  • Implementação do sistema de cadastro de mães e encontros
  • Funcionalidade de edição de encontros
  • Geração de relatórios em .txt
  • Criação da documentação técnica, incluindo modelo conceitual, lógico e diagrama de classes

Challenges & Learnings

Um dos principais desafios do projeto foi a interpretação dos requisitos do cliente e a tradução dessas demandas para regras de negócio e estrutura de dados.
Além disso, este foi meu primeiro contato com a criação de um banco de dados relacional, utilizando MySQL, o que exigiu aprendizado rápido sobre modelagem, relacionamentos e integridade referencial.
Outro grande desafio foi estar totalmente responsável pelo back-end do sistema, aliando isso a um prazo curto para entrega da atividade, o que demandou organização, priorização de funcionalidades e tomada de decisões técnicas eficientes.
