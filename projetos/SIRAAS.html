Project Overview & Goal

Sistema web desenvolvido no 1º semestre do curso de Análise e Desenvolvimento de Sistemas, como projeto avaliativo da disciplina. O objetivo principal do projeto foi criar uma plataforma centralizada para o gerenciamento de atestados médicos e o acompanhamento de equipes Scrum em um ambiente acadêmico. O projeto teve como foco tanto a aprendizagem técnica quanto a vivência prática da metodologia Scrum.

The Fullstack Architecture

  • Front-end desenvolvido utilizando HTML5 e CSS3
  • Back-end implementado em Python, utilizando o microframework Flask
  • Persistência de dados realizada por meio de arquivos de texto (.txt)
  • Modelagem dos casos de uso realizada com a ferramenta Astah

My Role & Core Contributions

  • Desenvolvimento do HTML e CSS da página do docente
  • Criação do HTML e CSS da página de estatísticas de afastamento
  • Estruturação do HTML da página de cadastro dos membros Scrum
  • Implementação do back-end do cadastro, utilizando Flask para receber os dados dos formulários e armazená-los em arquivos .txt
  • Modelagem dos casos de uso no Astah, colaborando para a documentação e entendimento funcional do sistema

Challenges & Learnings

Este projeto representou minha primeira experiência com programação. Iniciei a faculdade sem conhecimento prévio na área, o que tornou o desenvolvimento do SIRAAS um grande desafio técnico e conceitual.


Os principais desafios enfrentados foram:

  • Compreender a lógica de programação e o funcionamento do back-end
  • Trabalhar em equipe seguindo a metodologia Scrum
  • Entender conceitos de modelagem e organização de requisitos

Como aprendizado, o projeto foi fundamental para:

  • Consolidar os primeiros conceitos de desenvolvimento web
  • Desenvolver autonomia para estudar e resolver problemas técnicos
